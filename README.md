Shop System

A simple shop management system built with Python and FastAPI.

Features

- Manage shop products
- Track incoming stock quantities
- Record sold quantities
- Check remaining stock
- Store data in a database

Technologies

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Database

Project Files

- "main.py"
- "database.py"
- "models.py"
- "schemas.py"
- "static/"
- "templates/"
- "requirements.txt"

How to Run

Install the required packages using:

"pip install -r requirements.txt"

Then follow the instructions in the project files to start the application.
